# INT6140 ePortfolio

这是 WANG Yu 的 INT6140 课程 ePortfolio 静态网站。系统中的业务数据为虚拟示例。

## GitHub Pages 部署

1. 新建仓库，建议名称为 `int6140-eportfolio`。
2. 将本目录内的 `index.html`、所有 CSS / JavaScript、`assets/`、`systems/` 和 `.nojekyll` 原样放到仓库根目录。
3. 仓库 **Settings → Pages → Build and deployment**：Source 选 **Deploy from a branch**，分支选 **main**，目录选 **/(root)**，保存。
4. 等待 GitHub Pages 部署完成，使用 Pages 页面显示的正式网址访问。

打开网址后，请检查头像转头、系统抽拉、系统入口、文献卡片、雷达图、流程箭头、职业规划小车与规划弹窗。顶部的“动效：开启／减少”按钮可切换动效；手机版在页尾也可切换。

更新网站时，以完整最新发布目录替换原文件；不需要上传离线版 `preview.html`、本地原始材料或生成记录。
